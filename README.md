# lume-gf

My personal build of [Lume](https://github.com/bilipp/Lume), the open-source native IPTV player for Apple devices,
for my own iPhone/iPad and Apple TV. It is installed through TestFlight on my own devices only and is not distributed.

- Source: each build takes Lume's newest published release, unchanged except for the patches in `patches/` and
  a build-time identity (own bundle id and name, "Lume GF").
- Paid features: built with Lume's own "Sideload" configuration, which unlocks them by the developer's design for
  self-compiled builds. If you use Lume, consider supporting the developer via the App Store version.
- Licence: AGPL-3.0, like Lume. All credit for Lume goes to its developer and contributors.
- Lume's anti-piracy policy applies: this build ships no content and no providers.
